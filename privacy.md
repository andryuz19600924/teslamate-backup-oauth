# Privacy Policy

TeslaMate Backup is a personal application used only by its owner.

The application uses Google Drive API access to create, view, update, and delete only the files and folders that it creates in the owner's Google Drive.

Backup files are encrypted before being uploaded. The application does not collect, sell, share, or transfer personal data to third parties.

OAuth credentials and authorization tokens are stored locally on the owner's private server and are not shared with third parties.

Last updated: October 14, 2026.
